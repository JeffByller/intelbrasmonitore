# Intelbras Monitore - Coletor de Métricas OLT & MikroTik

Aplicação para coleta automatizada de métricas e status de equipamentos OLT Intelbras e roteadores MikroTik, com integração ao Telegram e armazenamento de histórico.

## 🚀 Funcionalidades

- **Coleta de Métricas OLT Intelbras**: Monitoramento de ONUs e portas pon.
- **Integração MikroTik**: Coleta de status e métricas de tráfego.
- **Notificações Telegram**: Envio de alertas de falha e eventos de rede.
- **Retenção Automatizada**: Purga diária programada de métricas antigas para otimização de memória e armazenamento.

## 🛠️ Tecnologias Utilizadas

- **Backend**: Python 3
- **Banco de Dados**: SQLite3 / PostgreSQL
- **Infraestrutura**: Docker Container
